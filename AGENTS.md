# Forge

A platform for making digital tools. Someone describes the tool they want, Claude
builds it, they edit it, and they publish it at a link — free or paid.

Read `README.md` for the product model before changing anything structural.

## Stack

- Next.js 16 (App Router, Turbopack) + React 19 + TypeScript
- Tailwind CSS v4 (configured in `src/app/globals.css`, no tailwind.config file)
- Supabase (Postgres + Auth), deployed on Vercel
- Claude (`@anthropic-ai/sdk`) builds and runs tools
- Paystack for payments

## Version-specific notes that bite

- `src/proxy.ts` replaces `middleware.ts`. Export a function named `proxy`.
  Runtime is nodejs and cannot be set to edge.
- `cookies()`, `headers()`, `params` and `searchParams` are all async. Await them.
- Route props types come from `PageProps<'/route'>` / `LayoutProps<'/route'>`,
  generated by `next typegen` (also run as part of `next build`).

## Claude API notes that bite

- Model is `claude-opus-5`. Never append a date suffix.
- Thinking is `{ type: 'adaptive' }`. `budget_tokens` is removed and returns 400.
- A tool spec is generated with `client.messages.parse()` +
  `zodOutputFormat(schema)` in `output_config.format`, so the model cannot
  return a shape the app then has to defend against. `parsed_output` is null
  when parsing fails — always guard.
- Assistant prefill returns 400. Use structured outputs instead.

## Conventions

- One engine per tool kind, all defined in `src/lib/engines/`. An engine owns its
  spec schema, its editor, and its runner. Adding a kind of tool means adding an
  engine, not touching the rest of the app.
- A tool's `spec` is validated against its engine's schema on every write. Never
  trust a spec read from the database without parsing it.
- Formulas and expressions authored by creators are parsed, never evaluated.
  `src/lib/expression.ts` handles arithmetic and nothing else — never reach for
  `eval` or `new Function`.
- Every table has row level security. A new table without policies is a bug.
- Published tools are readable by anyone, signed in or not. That is the point of
  a distribution link.
