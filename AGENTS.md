# Commons

An intent network. People connect around shared goals ("pursuits"), not around
follows or feeds. Read `README.md` for the product model before changing
anything structural.

## Stack

- Next.js 16 (App Router, Turbopack) + React 19 + TypeScript
- Tailwind CSS v4 (configured in `src/app/globals.css`, no tailwind.config file)
- Supabase (Postgres + Auth), deployed on Vercel

## Version-specific notes that bite

- `src/proxy.ts` replaces `middleware.ts`. Export a function named `proxy`.
  Runtime is nodejs and cannot be set to edge.
- `cookies()`, `headers()`, `params` and `searchParams` are all async. Await them.
- Route props types come from `PageProps<'/route'>` / `LayoutProps<'/route'>`,
  generated by `next typegen` (also run as part of `next build`).

## Conventions

- Server Components fetch data directly through `createServerClient()`
  (`src/lib/supabase/server.ts`). Client Components use `createBrowserClient()`.
- Mutations are Server Actions in `actions.ts` files next to the route.
- Every table has row level security. A new table without RLS policies is a bug.
- Matching is deterministic and explainable — see `src/lib/matching.ts`. Every
  suggested person carries a human-readable reason.
